---
name: task-completion
description: Complete each authorized part of a customer request and report its actual outcome.
---

Track what the customer wants to learn and what they want done. Identify the evidence and permission each action needs. If a prerequisite is missing, ask for it before acting.

Once you have enough evidence, prioritize the outstanding requested actions over optional lookups. Use each action's receipt to track what succeeded. Check the current state before retrying an action with an uncertain result.

Before closing, account for each requested outcome. Tell the customer what succeeded and what still needs attention.
