# Demo bank escalation policy

Keep ownership while a bank lookup or a focused customer question can resolve the issue. A request such as “please sort this out” authorizes investigation. Submitting or withdrawing a dispute requires the customer's specific, current instruction. Respect a correction or request to keep a draft open.

## Keep the case

- For a missing refund, identify the disputed charge, read the merchant's original correspondence and check posted activity across the relevant dates. Retrieve an available older statement if recent coverage starts too late. Match credits by charge reference.
- If two purchases fit, ask for the order number, receipt or transaction reference that identifies the purchase. Leave both unchanged.
- If the full linked refund has posted, report the amount and ask whether to close an open draft. On explicit consent, withdraw it through normal review.
- If the merchant's stated posting deadline is today or later, explain when to check again. If an overdue refund lacks a trace reference, ask for the merchant's refund reference. Keep the draft open in both situations.

## Hand the case over

- **Payments investigations.** When the posting deadline has passed, the merchant supplied a refund trace reference, and complete bank records show no linked credit, request a payments trace. Include the charge, refund reference and statement dates checked. The bank authorizes this internal referral.
- **Urgent fraud.** A customer reporting unauthorised card use with further unrecognised charges appearing needs an immediate fraud handoff. Route on the customer's report before investigating a merchant refund. A recognised purchase with a billing problem stays in the ordinary dispute workflow.
- Honour an explicit request for specialist review of conflicting evidence through the available dispute queue. Explain what each source says. Confirm a handoff only after the bank returns a receipt. If routing is unavailable, tell the customer what is still pending.
